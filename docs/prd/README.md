# Product Requirements

Full PRDs live here, one file per feature or initiative: `NNN-<slug>.md`.

- Index, lifecycle, and format: [`.ai/REQUIREMENTS.md`](../../.ai/REQUIREMENTS.md).
- Status lifecycle: `Draft → Approved → Implemented → Superseded`.
- Only an **Approved** PRD drives implementation, through [`.ai/workflows/feature.md`](../../.ai/workflows/feature.md).
- Do not duplicate requirements in `.ai/`; link to the PRD from the index.

This directory is empty until the first PRD is written. Keeping it in the repository makes the layout explicit for adopters.
